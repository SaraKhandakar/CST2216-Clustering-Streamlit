# Customer Segmentation (KMeans) — CST2216 Term Project

This project modularizes the Level-1 notebook Unsupervised_Clustering_Solution.ipynb and deploys a Streamlit app.

## Features
- Elbow plot (WCSS)
- Silhouette plot
- KMeans clustering (2D or 3D feature set)
- Cluster summary and visualization

## Run locally
```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
